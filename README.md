                                                Calculator Application
The Calculator is a desktop application developed using C# and Windows Forms, It provides a simple graphical interface to perform basic arithmetic operations.

Purpose                                       
The purpose of this project is to demonstrate:                                              
The implementation of event-driven programming in Windows Forms.                               
Designing a functional and user-friendly GUI for basic calculations.                              
Handling user input and performing dynamic computations programmatically.    

Features
Graphical User Interface (GUI):                                         
Intuitive and visually clear button layout for digits and operations.                                
Basic Arithmetic Operations:                                    
Addition (+)                          
Subtraction (-)                        
Multiplication (*)                                                
Division (/)                                 
Clear Functionality:                                       
A "Clear" button to reset inputs.                                   
Dynamic Display:                                          
The input and calculation results are shown in a display box.                                
Responsive Buttons:                                            
Each button dynamically updates the display based on the user input.                               

Technologies Used                                
C#: Programming language.                        
Windows Forms: For GUI design.                           
Visual Studio: Integrated Development Environment (IDE).
